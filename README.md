# Vita Mind

A calm, senior-friendly Mahjong Solitaire game built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start a local server from this folder:

```sh
python3 -m http.server 4173
```

The game includes 12 automatically advancing levels, five layered board layouts with 38 to 50 tiles per level, an illustrated tile collection tray, limited hint/undo/shuffle/magnet helpers, and sound settings.
